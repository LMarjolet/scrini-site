# scrini-site

Pages publiques de l'application **Scrini** : politique de confidentialité et
suppression de compte. Publiées par GitHub Pages, elles sont exigées par Google
Play pour toute application permettant la création d'un compte.

Ce dépôt ne contient que ces pages. Le code de l'application est ailleurs.

| Page | Rôle |
|---|---|
| `index.html` | Accueil, crédits TMDB, contact |
| `confidentialite.html` | Politique de confidentialité (RGPD) |
| `suppression-compte.html` | Procédure de suppression de compte |

Aucun script, aucune dépendance externe : ces pages doivent rester consultables
même derrière un réseau restrictif, et lisibles par un relecteur qui n'exécute
pas de JavaScript.
